# Raksha Bandhan — For My Diii 🪷

Files:
- index.html
- style.css
- script.js
- music.mp3 (add your own instrumental file)

## Music
Put an MP3 named `music.mp3` in this same folder. The page starts the music after the visitor taps "Open Your Surprise".
For GitHub Pages, only upload music you have permission to use. A short original/royalty-free Indian instrumental is ideal.

## GitHub Pages
Create a repository, upload all four files, then enable Pages from Settings → Pages → Deploy from a branch → main → /(root).
